# OptiStash

Warehouse Management System (WMS) of the OptiEcosystem. Runs standalone, or as a SaaS application managed from OptiNexus
(tenants, subscriptions, identity and permissions). Built on the same layers as OptiDeli: Laravel + PostgreSQL + React/TypeScript.

Ports (development): API 8400, UI 5210, dev server 5185, PostgreSQL 5545.

Product scope and delivery order: see `docs/status/CHECKPOINT.md` (source: "Breakdown Produk WMS OptiStash", six modules, ISO 9001:2015).

Local only: nothing in this repository is pushed to https://github.com/gsiddik/OptiStash until the owner asks for it.
